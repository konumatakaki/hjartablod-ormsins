3つに共通の中身と、その理由

  • QEMU と Standard PC (Q35 + ICH9, 2009): QEMU の仮想マシンの中では実際にこう読める。外の誰かが記録していることの、分かる人にだけ分かる手がかり。
  • Running on local URL: http://127.0.0.1:7860 と share=True の案内: Gradio が起動時に実際に出す文言。オフラインでも共有リンクの案内は出る。
  • [lang: is 0.34]: 音声認識の言語判定が、未知の言語をアイスランド語（言語コード is）と判定している。ホスト名と同じ言語。
  • MFCC の図の色: librosa の初期設定では、MFCC のように負の値を含むデータは青と赤の配色（coolwarm）で描かれる。虹色にするなら、誰かが配色を変えた理由が要る。
  • ユーザー名 analyst は仮。エンジニアが共用のアカウントとして作った、という想定。
