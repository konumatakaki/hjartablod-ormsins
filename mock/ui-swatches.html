前の版の書体が安っぽかった原因

  1. 指定した書体が、見る側の環境に入っていなかった。 DejaVu Sans Mono は Linux にはあるが、Mac や Windows やスマホにはない。英数字が、読み込んであった日本語書体（BIZ UDゴシック）の英字に落ちていた。日本語書体の英字は、日本語と並べるための設計なので、端末の文字としては別物に見える。
  2. 文字サイズが半端な値だった。 画面の幅に比例させていたので、11.37px のような端数になり、輪郭がぼやけていた。本物の画面は整数のピクセルで描かれる。
  3. 書体の出どころがばらばらだった。 端末、バー、道具の画面、字幕で、設定資料と関係のない書体が混ざっていた。

この版では、仮想マシンに実際に入っている書体（DejaVu Sans Mono、Liberation Mono、DejaVu Sans）を、使う文字だけに絞って同梱した。道具の画面は、Gradio が同梱している Source Sans Pro。どの書体がどこに出るかも、初期設定から導いている。

第3版での修正: 実物の dwm、st、Gradio を動かして撮った画面と照合し、バーの文字の大きさ、窓のあるタグの印、Gradio の書体とボタン、起動時の出力の文言を直した。照合の結果は docs/design-rules.md にある。

残る差: Linux は文字の輪郭を画素の格子に合わせて描く（ヒンティング）が、Mac のブラウザはそれをしない。同じ書体でも、Mac で見ると少し柔らかく見える。気になるなら、最終的にはゲーム側で文字の描き方を揃える方法を検討する。
