# 台本の書き方（早見表）

台本は ink という形式で書く。ただし、使う記号は下の表の分だけでよい。
地の文と台詞は、ふつうの日本語の原稿とほぼ同じ書き方になる。

## 最小限の約束

| 書きたいもの | 書き方 | 例 |
|---|---|---|
| 内省（地の文） | ふつうに書く | （内省の文） |
| 台詞 | 名前と鉤括弧 | `リーダー「（台詞）」` |
| 通信（イヤホン越し） | 台詞の行末に `#通信` | `エンジニア「（台詞）」 #通信` |
| ルビ | いつもの記法 | `|椅子《いす》` |
| 用語の掘り下げ | 二重の角括弧 | `[[有気音]]` |
| Claude へのメモ | 行頭に `//` | `// ここで絵カードを見せる選択肢` |

`//` のメモは、ゲームの画面には出ない。選択肢や演出の指示は、メモで書いてもらえれば Claude が ink の形に直す。

## 避けること

ink で特別な意味を持つ記号がある。地の文で使うと、文章として扱われなくなる。

- 行頭の `*` `+` `-` `=` `~`（地の文の行頭にダッシュを置かない。置きたいときは、行頭を全角にする）
- 文中の `#` `{` `}` `->` `<>` `//`

## 2種類の場面

| 場面 | 書く人 | 書き方 |
|---|---|---|
| 読む場面（車内、食堂、報告書など） | オーナー | 上の約束だけで、ふつうに書く |
| 操作のある場面（聞き取り、分析） | 骨組みは Claude、文章はオーナー | Claude が選択肢と分岐の骨組みを作り、文章の入る場所を空けておく。オーナーはそこを埋める |

### 操作のある場面の骨組みの例

括弧の中を、オーナーが書く。Claude は台詞を書かない。

```ink
=== day1_session2 ===
#場面 2026-10-15 13:10 / 面接室 / 聞き取り2
（内省: 聞き取りを始める前の主人公）

* [見せる: 絵カード「パンを食べる人」]
    #show_card: bread
    #utter: g_014
    （内省: 少女の反応を見た主人公）
    -> bread_reaction
* [待つ]
    #utter: g_015
    （内省: 待った結果）
    -> waited

= bread_reaction
（内省）
リーダー「（台詞）」 #通信
-> END

= waited
（内省）
-> END
```

- `#show_card` や `#utter` のような `#` で始まる行は、演出の指示（タグ）。Claude が入れる。
- `*` の行が選択肢。`->` は「この場面へ進む」。

## ファイルの置き場所

```
content/
  script/       台本（ink）。1日ごと、場面ごとのファイル
  notes/        学部のノート（1回1ファイル）
  glossary/     思考（一回だけの掘り下げ）と用語
  utterances/   少女の発話（ELAN の .eaf と、語彙の表）
  images/ audio/
```
