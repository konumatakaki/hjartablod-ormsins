# 前提と決定事項

## 動機と、描くもの

- 『あなたの人生の物語』は言語を深く扱うが、道具の描写が薄い。『プロジェクト・ヘイル・メアリー』は道具を出すが、言語を暗号のように扱う。両方をやった作品がない。その寂しさへの返答として作る。
  **道具は濃く見せ、言語は暗号として扱わない。**
- 描きたいのは**概念の獲得と分析**であって、作業そのものではない。
- ゲーム内の操作は、厳密な照合である必要はない。リズムゲームや並べ替えゲームでもいい。ただ、実際の言語学の操作と似ていると嬉しい。
  （Claude の言い換え: **操作の形は本物から借り、手間は抽象化する**。具体例は mechanics.md）

## 主題と体験

- 中心になる問い: **「現代の道具で、接点の少ない言語を解読するとどうなるか？」**
- 扱う範囲: 言語学と言語哲学のそれなりに広い範囲
- プレイヤーが楽しむのは主に**雰囲気**。
- ゲームの回し方は**逆転裁判**に近い。矛盾を見つけて突きつけ、そこから生まれた新しい謎の中でまた矛盾を探す。
- 解読そのものは演出寄り。ただし**道具は本物**にする（例: メル周波数ケプストラム係数（MFCC）を虹色で流す可視化）。
  - 「本物」とは、本物らしく見えるように表現すること。実際に計算する必要はない（Papers, Please もパスポートのホログラムまでは作っていない）。
  - ただし、少女が実際に音声で話してくれたらとても嬉しい。
- 狙い: 「言語解読ゲーム＝言語学オリンピックのような推理パズル」というイメージを、**道具の側を強調すること**で崩す。
- 参照
  - 演出: 映画『メッセージ（Arrival）』の解析画面（Wolfram 親子が実際にコードを書いたもの）
  - UI の手触り: Papers, Please、Hacknet
- あらすじのたたき台 → `synopsis.md`

### 対応関係（オーナーが「おおむねこれに近い」と確認済み）

逆転裁判の「証言 vs 証拠」を、「**主張 vs 道具の出力**」に置き換える。
登場人物の翻訳・仮説・思い込みが証言にあたり、スペクトログラムや統計といった本物の道具の出力が証拠にあたる。
プレイヤーは頭の中で解読するのではなく、**道具を操作して、主張と食い違う出力を選んで突きつける**。
この形なら「言語学オリンピック的なパズル」から自然に離れられる。

### 世界のルール（設計上の公理）

- 少女はホモ・サピエンスである。
- 音声言語は線状性を持つ（Saussure）。
- 少女の言語は、普遍文法の枠組みで分析できる。
  ここでの「普遍文法」は、「それなりに拡張でき、たいていの情報伝達の概念を詰め込める便利な袋」くらいの意味。
- 弱いサピア＝ウォーフ仮説は成り立つ（言語が思考に影響はするが、決定はしない）。
- 少女は文字を知らない。

（Claude 注: 普遍文法の存在は、現実の学界では争われている。Evans と Levinson の批判や、Everett のピダハン語をめぐる論争など。
このゲームの中では公理として扱う。登場人物の議論の種にはなりうる）

### 少女の描き方（確定）

- 「遅れた文明の人間」としては描かない。
- 少女は、自分の前提（ここは死後の世界）のもとで筋の通った解釈をしている。驚くよりも、「そういうものだ」と納得したうえで、我々から見て誤解している。
  - 例: 鏡があるなら、前世が映るのだろうと思っている。
  - 例: 絵が動いても、そういうものだとすぐに順応する。
  - 例: 審判者（チーム）を、巡察に来た聖職者や寄進の調整に来た領主のような、「大変そうな偉い人」の枠で見ている。
- （Claude 補足）中世ヨーロッパの教会には、司教が修道院や教区を回って規律を調べる「巡察（visitation）」の制度が実際にあった。
  決まった質問をされ、職務や行いについて答える。少女にとっての「死後の審判」は、畏怖の対象というより、こういう手続きの延長として描ける。
  こちら側が倫理委員会の書類を出す組織なので、両側とも官僚的な手続きを生きている、という対称にもなる。
- （Claude 補足）人類学でも、フレイザーの「呪術 → 宗教 → 科学」という進化論的な見方は、Evans-Pritchard のアザンデの妖術研究（1937年）などで覆されている。前提を共有すれば、信念の体系は内側から見て合理的だ、という見方。
  作中では、素朴な概念を持っているのは言語学者の側で、文化人類学者のリーダーが「いつの時代の話をしているんだよ」と正す。
- （Claude 補足）東アジアの仏教でも、閻魔の庁には死者の生前の行いを映す「浄玻璃の鏡」がある。死後の審判と、行いを映す鏡の結びつきは、現実の宗教にも見られるモチーフ。

### 専門家の描き方（確定）

- **専門家は、専門用語を正しく使う。**
- そのうえで、派閥の癖や、内輪の論争の中での立ち位置はある。
- 知識の水準の目安: 言語学者なら、SEP（スタンフォード哲学百科事典）の "Philosophy of Linguistics" の項目をレジュメにして、しばらく話せる程度。
- （Claude 補足）その項目は、言語学の基本的な立場を3つの傾向に分けて整理している。
  - 外在主義（Externalists）: 観察できる発話やコーパスを対象にする
  - 創発主義（Emergentists）: 言語は伝達や社会的な相互作用から生まれる
  - 本質主義（Essentialists）: 生成文法系。人間に内在する言語能力を対象にする
  主人公の素朴さは、用語の誤用ではなく、**自分の派閥の前提が死角を作る**形で出すのがよい。
- 素朴な概念を持つ方向は、分野をまたぐと対称になる。言語学者は文化や宗教についての古い見方を持ちがちで、人類学者は言語学についての古い見方を持ちがち。
- 分野外の用語を緩く使うことはありうる（例: 言語学者が機械学習の用語を）。その場合は、その分野の専門家が正す。

### 道具の能力（確定）

- **道具は証拠を出す。結論は出せない。**
- 「出さない」という設計上の制限ではなく、「出せない」という世界の事実として扱う。
- 過去作で AI が結論まで出せたのは、近未来の設定で AI がすごかったことと、少女が異常だったことによる。今回はどちらも当てはまらない。
- 結論らしきものを出す道具（翻訳 AI など）はあってもよいが、信頼できないものとして登場する。
- 時代は現代くらいなので、万能の翻訳 AI は出せない。方向性を決めれば言語カードを出せるし、パターンが分かれば音声から構文木を自動で作れる（精度は不明）。詳細は tools.md。

### 表記の層（確定。細部は仮）

解読の進み具合を、言語をどの解像度で表記できるかで見せる。

1. スペクトル（音そのもの）
2. 精密表記の IPA `[ ]`
3. 音素表記 `/ /`（どの音の違いが意味を区別するか）
4. ラテン文字への転写
5. 形態素分割とグロス（ライプツィヒ・グロス規則の行間注釈）
6. 構文木など、言語学特有のツール

方針: **安易な日本語の直訳は出さない。**

#### Claude の整理（オーナー未確認）

- 言語学の行間注釈は「原文 / 形態素分割 / グロス / 自由訳」の4行になっていて、最後の自由訳が一番あやふやになる。
- そこで、**自由訳（日本語訳）は道具の出力としては出さない。登場人物の口から仮説として出す**。自由訳は証言、表記とグロスは証拠という分担になる。
- 抽象化の段階が上がるごとに、情報が捨てられる。たとえば、異音だと判断して捨てた音の違いが、実は意味を区別していた、という具合。
  つまり、**下の層に戻ると、上の層の間違いの証拠が残っている**。層は進捗であると同時に、証拠の地層でもある。

### 専門用語の注釈（確定。細部は仮）

- 主人公の一人称の思考（内省）には、専門用語がそのまま出てくる。
- 専門用語は色を変えて表示する。カーソルを合わせると、主人公がプレイヤー向けに思考を深めてくれる。
- 参考: Paradox 社のゲームのヘルプ（注釈の中の用語にも注釈がある、入れ子のツールチップ）。
- 実装メモ（Claude）:
  - 本文の書式で用語に印を付ける。用語集は別のファイルにして、オーナーが直接編集できるようにする。
  - タッチ操作にはカーソルを合わせる動作がないので、タップで代用する必要がある。

## 実装の共有方針（仮）

- 台本・辞書・設定などのデータは、コードを触らなくても編集できる形式にする。
- 事前の解析処理（音声 → MFCC など）は、なるべく読みやすい Python で書く。
- ブラウザ側のコードは仕組みを `docs/` で文章として説明する。読めなくても全体像は分かるようにする。

- 常体で話す。結論を先に言う。前置きと褒め言葉は省く。

- 確かな知識、推測、好みを区別して書く。
- 質問は一度に3つまで、優先度の高い順に。
- オーナーの返事は詳しく書く。曖昧なところはお互いに詰める。
- 分からないことがあるのは問題ない。片方が知っていればそれで対応し、どちらも知らなければ調べるか試す。
