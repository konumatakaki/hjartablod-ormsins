# 文体メモ

参照元: `reference/chouetsu-shoujo-ch1.md`（オーナーの過去作『超越少女は路を示すが旅をするのは俺達だ』第1章）
Claude による言語化。オーナーの確認待ち。違っていれば直す。

## 語り手の声

- 一人称の内省が主体。台詞は短く、その後に1〜3段落の思考が続くのが基本のリズム。
- 乾いた自嘲。「どうせ俺は石油を蒸留して何ができるかをもはや言えなくなってしまった人間だよ」
- 道具やシステムへの内心のツッコミ。「全部お前がやれよと言いたくなる」「それならもう少し唇の読み取りを正確にしろよ」
- 読者への直接の語りかけ。「あんまりアイヌ語でそういう言い方はしないだろとかいうのは置いといてくれ」
- 地の文が、ときどき冗談として、です・ます調に崩れる。「というような推理を先程BIFRONSがしていたんです。」
- 文末は常体の口語。「〜だろう」「〜な」「〜よな」「〜けど」。「うん、」「さて、」「まあ」で始める文がある。

## 知識の出し方

- 説明した直後に、留保か自分の限界で落とす。
  例: エクマンの理論を説明し、「まだきちんと受け入れられている学説というわけではないが、俺はかなり良くできた理論だと思っている」で締める。
- 教養ネタを説明なしで投げる（sudo、ノタリコン、Lincos、ゴールデンレコード、ゴーギャン）。通じなくても話は進む。
- 社会批評の脱線がある（言語の消滅、少子化、AI と労働、宇宙開発）。数段落続くこともある。

## 人物と身体の描写

- 外見描写は少ない。主人公は人の外見を覚えられない、という設定と一致している。
- 表情は筋肉の動きとして描く（上瞼、下瞼、口角）。主人公は表情を記号として読み、自分の表情も意図して作る。
- 相手との距離感は、ミラーリング、会話の量、ターンの間合いといった観察で描く。

## 道具の描写

- 道具の出力を、行頭の「── 」で独立した行として示す。
  例: 「── 表情ミラーリング: 可能性」「── 会話量の対応: 可能性高」
- 理解できない発話は「███」の伏せ字で、長さだけを示す。長さそのものが分析の材料になる（会話量の対応）。
- 実在の技術の名前をそのまま出す（MFCC、IPA の精密表記、フォルマント、特徴点抽出）。
- 書式: ルビは `|漢字《よみ》` の記法。見出しは「章題 番号」。

### Claude の読み（オーナー未確認）

- **過去作で言語が「入口」で終わった理由:** インフォーマントが日本語を急速に習得するので、解読という問題が消えてしまう。
  今回は少女を普通の人間にしたことで、解読がずっと物語の中心に残る。構図としては、過去作をほぼ反転したものになっている。
- **道具の能力の上限を決めておく必要がある:** 過去作のように道具が結論まで出すと、プレイヤーがすることがなくなる。
  案: **道具は証拠を出すが、結論は出さない。結論を出す道具（翻訳 AI など）は、信頼できないものとして扱う。**
- **「███」の伏せ字は、表記の層の0段目として使える:** 最初、少女の台詞は伏せ字で長さだけが見える。
  層が解放されるたびに、同じ台詞がスペクトル、IPA、転写、グロスへと変わっていく。テキストの欄そのものが解読の進み具合を表示する。
- **「── 」の行は、道具の出力の表示としてそのままゲームの UI にできる。** 地の文、台詞、道具の出力という3種類の声を、見た目で区別する。
- **脱線の扱い:** 長い社会批評や知識の脱線は、固定画面のノベルゲームでは一画面に収まらない。
  用語の注釈（ツールチップ）に逃がすか、全画面にテキストを表示する形式（NVL）を採用するかで、扱いが変わる。
- **ルビの記法 `|漢字《よみ》` は、台本の形式にそのまま採用できる。** オーナーが書き慣れた記法で台本を書ける。
