# あらすじ（たたき台）

名前や職業などの細部は変わりうる。大きな方針は今のところ変えない。
（カッコ内）はメタ情報で、プレイヤーには直接見せない。

## 導入

- 「私」は某大学の教員（言語学者）。性別は明かさない（趣味）。
- 雨の中、車で移動している。ルームミラー越しに目が合う彼女が今回のチームリーダー。
  民間コンサルティング会社に勤める文化人類学者。
- 「組織」は、暇な専門家に副業を回してくれる便利な組織。どうやら碌でもないところらしい（財団のようなもの。ただし貧乏）。（マクガフィン）
- 依頼は「異言語の解読」。車内で簡単なブリーフィングがある。
  - 言語解読には一般に、ロゼッタストーン・コーパス・トーカー（話者）のどれかが要る。
  - 現代では、たいてい通訳が間に入る。完全に未知の言語の解読はほぼありえない。
  - そんな依頼が、それも場末の言語学者に来る。碌でもない。

## 舞台

- 病院か何かを改装したらしい施設。壁には鏡がある。
- インフォーマントはアクリル板の向こうにいる。
- カメラ、マイク、ノートパソコン、ディスプレイ。
- 部屋に入る前に握手したエンジニアが、言語学で必要そうなものを一通り入れたというノートパソコンを紹介する。
  周波数解析、統計処理、体の動きや表情の分析などが詰まったツールボックス。
  （物語が進むと新しいツールが解放される。裏でエンジニアがヴァイブコーディングしている）

## インフォーマント

- アクリル板の向こうの少女。真面目そう。
- （実は、中世風の世界にある宗教施設の保育施設で働く保育士。自分は死後の世界に来たと思っていて、審判に備えて真面目にしている）
- そのため、何かを指さして名詞を教え合うというよくある始め方にはならない。
  （クリシェだから避けたいのもあるし、ガヴァガイ問題を起こしたい）
- 我々が向こうの言語を学ぶのが話の中心。

## 時間制限

- 約1週間。理由は「私」が雇われの身で、次の授業を休めないから程度でいい。
- 1日が1話。

## 少女の態度の変化

- 最初は真面目。審判を受けているつもりでいる。
- 途中から「こいつら、言葉もわからないガキじゃん」になる。
- 第1話は、少女が「あれ、こいつら審判者じゃないな？」と気づくところで終わる。
- 第1話の終わりは、道具の側から見ると「丁寧な話し方に過学習したモデルが、俗な話し方に対応できなくなる」出来事になる。
  辞書の多くはそのまま使えるので、子音や母音の範囲を広げて再チューニングすればいい（第2話の入り）。
- （Claude 案）道具の方が先に気づく。少女の態度の変化は、まず精度のバーの急落として画面に現れる。
  主人公がその理由を理解するのは後。第1話の引きは「精度が急に落ちた。なぜ？」になる。

## 要約

異世界から転移してきた少女の言語を解読する話。転移に理由はない。
半分はお約束で回し、もう半分は現実の道具で回す。
