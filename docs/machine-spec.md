# マシンの設定資料（下書き）

画面に出るすべての文字は、ここから導く。決まっていないところは「未定」と書く。
OS の GUI を本物どおりに再現する必要はない。ただし、軽くて古い見た目の、あのチープな感じは欲しい（オーナー）。

## 全体の構成（Claude が決定。オーナーの委任による）

ノートパソコンに Linux を直接入れ、その上に**仮想マシンを一枚挟む**。

| 層 | 誰が用意したか | 中身 | 目的 |
|---|---|---|---|
| ホスト | 組織 | 最小構成の Linux。画面なしで起動し、すぐに仮想マシンを立ち上げる | 作業の記録。仮想マシンの画面、入力、ファイルの出入りを、中から見えない場所で記録する |
| ゲスト（仮想マシン） | エンジニア | 作業用の Linux。GPU をホストから丸ごと渡している（パススルー） | 主人公が触る環境 |

- 主人公は、ゲストの中しか見ない。記録されていることは知らされていない。
- 「仮想マシンを挟む理由」が「監視」になる。組織の碌でもなさの、もう一つの静かな裏付け。

## 各層の詳細（案）

### ハードウェア

- モバイルワークステーション級のノートパソコン。メーカーは架空（ロゴを出すなら架空のもの）。
- GPU: VRAM の多いノート向け GPU。具体的な型番は未定（実在の型番を出すかどうかも未定）。
- 無線 LAN はハードウェアのスイッチで無効化されている。

### ホスト（組織）

- OS: Debian の安定版（未定。2026年時点なら Debian 13 が候補）。
- ディスク全体を暗号化（LUKS）。起動時にパスフレーズの入力が出る。
- ホスト名: 組織の資産番号のような名前（未定）。
- ほとんど画面に出ない。起動の最初の数行と、パスフレーズの入力画面だけ。

### ゲスト（エンジニア）

- OS: Ubuntu の LTS 版（CUDA が入れやすいので、機械学習のエンジニアの定番。確度中〜高）。
- 仮想マシンの痕跡: 起動ログに `DMI: QEMU Standard PC (Q35 + ICH9, 2009)` のような行が出る（QEMU の仮想マシンでは実際にこう表示される。確度高）。
  分かる人にだけ、「これは仮想マシンだ」と分かる。
- 起動画面: エンジニアがロゴ表示（splash）を切っているので、起動ログがそのまま流れる。
- ウィンドウマネージャ: 軽くて古い見た目のもの。資源を機械学習に回すため、というのが理由。具体的な見た目は未定（下の「見た目の方向」）。
- ホスト名: **`hjartablod-ormsins`**（エンジニアが付けた）。
  - アイスランド語の Hjartablóð ormsins（竜の心臓の血）。シグルズがファーヴニルの心臓の血を舐めて鳥の言葉が分かるようになる場面から。
  - ホスト名には ASCII の英数字とハイフンしか使えない（RFC 952 と 1123）ので、ó と ð が落ちて `hjartablod` になっている。言語学者でもすぐには何語か分からない理由になる。
  - 場面（オーナー案）: 主人公が何語か悩み、リーダーが「heart-blood？」と気づく。
  - （Claude 補足）フレイザーには、蛇を食べて動物の言葉が分かるようになる、という民話を集めた論文 "The Language of Animals"（1888年）がある（確度中）。フレイザー好きのリーダーなら気づける。
- ユーザー名: 仮に `analyst`（エンジニアが作った共用のアカウント）。未定。
- ネットワーク: 仮想マシンにはネットワークの装置自体を付けていない。ステータスバーは常に「OFFLINE」。

### ソフトウェア（案）

- Python 3.12、PyTorch、CUDA 12 系
- 音声: librosa、Praat（Parselmouth）、ffmpeg
- 音声認識と音素認識: Whisper（ローカル）、wav2vec2 系の音素認識モデル、Allosaurus
- 道具の画面: Gradio と Streamlit（ローカル）
- 分析: JupyterLab
- 翻訳 AI: **ローカルで動く公開モデルの LLM**。オフラインなので、最先端の大型モデルは使えない。
  → 翻訳 AI の信頼できなさに、技術的な理由が付く。

## 道具が届く仕組み

- エンジニアは別の部屋（ネットワークあり）でヴァイブコーディングしている。
- 仮想マシンはオフラインなので、新しい道具は USB メモリで持ち込まれる。
- **道具の解放 = USB メモリが挿される。** 端末に、マウントのログ、展開のログ、新しいタブの起動が流れる。画面に出る文字すべてに理由が付く。

## 図の配色

- librosa の初期設定では、MFCC のように負の値を含むデータは青と赤の配色（coolwarm）で描かれる（確度中〜高）。
  虹色（jet など）にするなら、誰かが配色を変えた理由が要る。

## 見た目の方向（未定。オーナーに確認する）

見本: `mock/ui-swatches.html`

「軽くて古いデザインのチープな感じ」の解釈の候補:

- **(a) 平らで暗い最小構成:** 上端の細いバー、タグ番号、等幅の小さなビットマップ風フォント。suckless の dwm などの系統。
- **(b) 立体の縁取りの灰色:** 盛り上がったボタン、灰色の窓枠、古いビットマップフォント。IceWM、Motif、昔の Windows の系統。
- **(c) 2000年代の軽量 Linux デスクトップ:** Openbox と細いタスクバーの組み合わせ。少しだけテーマが付いている。
