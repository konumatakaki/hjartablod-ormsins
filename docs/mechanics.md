# 操作のネタ帳

実際の言語学の操作を、その形を残したままミニゲームに落とす案。**すべて例。**

## 2つの層

- **作業の層:** ミニゲーム。本物の操作の形を借りて、証拠を作る。
- **推論の層:** 逆転裁判のループ。証拠を突きつけて、概念を獲得する。

概念の獲得は、道具の表示が一段増える形で見せられる（例: 「声調」という概念を得ると、転写にピッチの欄が増える）。
「表記の層」（premises.md）と同じ構造になる。

## 本物の操作 → ミニゲームの形

| 本物の操作 | 何をしているか | ミニゲームの形の案 |
|---|---|---|
| 分節 | 音の流れに切れ目を入れる | リズムゲーム。音節の境界で拍を刻む。少女の言葉遊び（音節の入れ替え）とも接続できる |
| 最小対 | 1か所だけ違う2語を見つけ、その違いが意味を区別するか確かめる | 間違い探し。2つのスペクトルを重ねて比べる |
| 音素の判定 | 2つの音が同じ音素か、異音かを決める | 仕分け。Papers, Please のハンコのように、許可・却下の要領で振り分ける |
| 形態素の分割 | 繰り返し出てくる断片を切り出す | 文を切り分け、共通する断片を揃えていくパズル（Chants of Sennaar に近い） |
| 活用表 | 形の変化を表にまとめる | 表の空欄を埋めるパズル |
| 構文木 | 語のまとまりと階層を見つける | 括弧や枝をドラッグして組み立てる |
| 声調 | ピッチの曲線を聞き分ける | 曲線をなぞる、または合わせる |
| 聞き取り | どう質問すれば欲しい情報が出てくるか | 会話の選択肢。逆転裁判の「ゆさぶる」に近い |
| 対応付け | 語と意味、または語と語を結びつける | 線つなぎ |

## 規模の注意

ミニゲームは種類ごとに実装の手間がかかる。半月で作るなら、まずは1〜2種類で作る。
