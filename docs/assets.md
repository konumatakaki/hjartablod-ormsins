# 素材の仕様（案）

## 画像の解像度の基準

- 画面の論理解像度は 1280×720、素材は2倍（tech.md）。
- カメラの窓（トリミング後）は論理 704×700 前後 → 素材は 1408×1400 前後あれば足りる。
- 作中のカメラは 1920×1080 の映像で、その中から顔の周りを切り抜いている、という設定。

## 見本（mock）の確認用に、最初に欲しい画像

| 画像 | 枚数 | 内容 | 何を確かめるか |
|---|---|---|---|
| 少女、正面 | 1〜2 | 目の高さのカメラから、ほぼ正面。上半身と、机の上の手まで入る。表情は真面目。病院の個室のような部屋、平たい蛍光灯の光。背景は壁 | カメラ風のフィルターとの相性、トリミング、特徴点の重ね方、字幕や通信や内省の帯との重なり |
| 入館証の写真（リーダー、エンジニア） | 各1（任意） | 証明写真。胸から上、正面、無地の背景、平たい光 | 通信の欄の写真の大きさと見え方 |

生成の目安（NovelAI）:

- 横長（1216×832 など）で生成し、2倍に拡大してから顔の周りを切り抜けば、1408×1400 に届く。
- 手を胸の前で組んだ姿勢にしておくと、見本の中のリーダーの通信（「両手、胸の前で組んだまま」）と合う。

## 見本画像の加工（実施済み）

- オーナーの見本画像（少女、リーダー、エンジニア。いずれも低解像度）を `mock/local/` に置いた。このフォルダは Git の管理から外してある（公開するかは未定のため）。
- `mock/src/camera_filter.py`: 背景（ほぼ白）を抜き、少女を病院の個室風の壁の前に置き、カメラの映像らしい処理（少しのぼかし、蛍光灯の色、粒子、色ずれ、周辺減光、アクリル板の映り込み、JPEG の圧縮）を掛けて 1408×1400 にする。入館証の写真は顔の周りを切り抜き、証明写真の背景に置いて 68×84 にする。
- `mock/src/with_images.py`: 見本の HTML に画像を埋め込んだ版（`mock/local/interview-images.html`）を作る。
- 気づいたこと: 元画像の解像度が低いので、拡大するとドットの輪郭がぼやけて残る。本番の素材は、2倍の解像度（1408×1400 程度）で生成したい。

## 未決

- **絵柄の現実味の度合い。** 画面はまあまあリアルな仮想マシンなので、アニメ調の顔がカメラの映像として浮く可能性がある。
  - アニメ調をお約束として受け入れる（逆転裁判のように）
  - 半写実の塗り（絵画調）に寄せる
  - 写真調（生成が難しく、不気味さが出やすい）
  → 数枚で試して、カメラ風のフィルターを掛けた見え方で決める。
- **少女の服装。** 自分の服（宗教施設の保育施設の職員の服）か、施設が用意した病衣か。
- 生成した画像を、公開されているこのリポジトリに置くかどうか。置かないなら、画像のフォルダを Git の管理から外す。
