# 架空言語のネタ帳

**ここにあるのはすべて例。** 実装上の問題を踏まえて、要素レベルまで分解して組み直す可能性がある。
採用が決まったものだけを premises.md へ移す。

## オーナーが挙げた例

| アノマリー | 現実の例 | 証拠が残る場所 | 何が崩れるか |
|---|---|---|---|
| 声調 | 中国語、タイ語、ヨルバ語 | ピッチ曲線（F0） | 同音異義語だと思っていた語が、実は別の語だった |
| 無気音と有気音の区別 | 韓国語、ヒンディー語、タイ語 | 有声開始時間（VOT） | 主人公の耳。日本語話者には区別しにくい |
| 目線や手振りで意味が逆になる | ブルガリアの頷き、日本語の「マジでヤバい」 | 映像のみ | グロス。「下の層に戻れば証拠がある」という構造そのもの |
| 硬い公式言語と柔らかい俗言語 | 二言語併用（Ferguson）、ジャワ語の話し方の段階、教会ラテン語と俗語、敬語 | 語彙の対応表、頻度 | 昨日作った辞書 |

全部を1つの言語に入れても不自然ではない。タイ語には、声調、有気音の区別、王族や僧侶に使う特別な語彙の体系がすべてある。

## Claude が追加した候補

### 文法

- **証拠性（evidentiality）**: 「見た」「聞いた」「推測した」など、情報の出どころを文法で必ず示す。トルコ語、ケチュア語、トゥユカ語など。
  審判の場で証言するなら、少女の発話には出どころの標識が付き続けるはず。証言のたびに出どころが文法で明示される言語。逆転裁判との相性は最も良い。
- **意外性（mirativity）**: 「新しく知って驚いた」ことを示す文法的な標識。
  第1話の最後、「あれ、こいつら審判者じゃない？」が、この標識の初出になる、という使い方ができる。
- **包括と除外の「我々」（clusivity）**: 聞き手を含む「我々」と、含まない「我々」を区別する。
  少女が審判者を「我々」に含めるかどうかで、関係の変化が文法に出る。
- **有生性**: 名詞を、生き物か物か霊かで分類する文法。
  少女がチームをどの分類で呼ぶかで、我々をどう見ているか（死者、霊、審判者、子ども）が分かる。
- **能格性**: 自動詞の主語が、他動詞の目的語と同じ形で標示される。「主語」という前提がグロスの段階で崩れる。
- **否定疑問への答え方**: 日本語は「はい（あなたの言う通り、行かない）」、英語は「No（行かない）」。
  少女の「はい」が何を肯定しているのか取り違える、という小さな矛盾に使える。

### 音

- **口笛言語**: カナリア諸島の Silbo Gomero など。スペクトログラム上では、1本の澄んだ線として見える。
  離れた子どもを呼ぶ手段としてなら自然。
- **母音調和**: 語根に合わせて接尾辞の母音が変わる（トルコ語、フィンランド語）。同じ接尾辞が、別の2つの形態素に見える。
- **借用語の音の適応**: 少女が我々の名前をどう発音するかで、彼女の音韻体系が逆にわかる。主人公があだ名を付けられる展開にもできる。

### 意味と語彙

- **絶対方位**: 左右ではなく東西南北で話す（グーグ・イミディル語）。
  窓のない施設では方角がわからない。少女の空間表現が崩れるか、「鏡の方」「祭壇の方」のような独自の基準に置き換わる。
- **時間の前後と身振り**: アイマラ語では過去が前、未来が後ろにあるとされ、未来の話をするとき後ろを指す（Núñez と Sweetser の研究）。
  オーナー案の「身振りで意味が逆になる」と、現実の根拠つきで接続できる。
- **語のタブーと言い換え**: オーストラリアの「義母語」など、特定の相手の前で使う別の語彙。
  審判者の前では口にできない語があり、言い換えられている。
- **定型句**: 祈りのような決まり文句は、形態素に分解しても意味がとれない。分解する道具が空振りする。

### 語用論（言葉の使われ方）

- **相槌**: 日本語話者は相槌が多い。少女には、それが同意にも、割り込みにも見えうる。
- **ターンの間合い**: 発話と発話の間の沈黙の長さ。タイミングを解析する道具の題材になる。
- **子どもに向けた話し方**: ゆっくりで、抑揚が大きく、構造が単純（既出）。
- **聞き取りの役割の逆転**: 保育士である少女が、こちらから言葉を引き出し始める。

### 文字

- **少女は文字を書けるか**: 宗教施設の職員なら、読み書きができてもおかしくない。
  話者自身の表記は、どの音の違いが意味を区別するかについての、話者の直感の証拠になる（たとえば声調を書かない文字体系なら、その手がかりになる）。
  小道具としても強い。ただし、文字の形は AI での画像生成では一貫させにくいので、フォントや SVG で自作する必要がある。

### 言語哲学

- **翻訳の不確定性（Quine のガヴァガイ）**、**根本的解釈と寛容の原理（Davidson）**: 採用済みの方向性。
- **言語ゲーム（Wittgenstein）**: 『哲学探究』冒頭の「台石！柱石！」の原始的な言語ゲーム。「意味とは使用である」。
  「ライオンが話せたとしても、我々には理解できないだろう」。
- **直示語（「私」「ここ」「今」）**: 少女にとっての「ここ」は死後の世界。
- **含意（Grice）**: 言外の意味。皮肉。
- **強いサピア＝ウォーフ仮説**: 学術的には疑わしい扱いが一般的。
  登場人物（たとえば文化人類学者のリーダー）の主張として出し、突きつけて崩す対象にできる。
- **機械翻訳と大規模言語モデル（中国語の部屋）**: 「流暢な日本語訳を即座に出す AI」を道具の1つとして登場させ、それが自信満々に間違える。
  「安易な日本語の直訳を出さない」という方針を、ゲームの主題として回収できる。

### 倫理

- **フィールドワークの同意**: 少女は研究への参加に同意できる状態にない。組織が碌でもないことの、静かな裏付けになる。
